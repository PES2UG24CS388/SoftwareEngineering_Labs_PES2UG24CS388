
# Lab 2: Agile Project Management Using Jira

## Project
**Hospital Bed & ICU Allocation Dashboard**

## Objective
To organize and manage project activities using Agile project management practices and Jira.

## Deliverables
- Product backlog with epics and user stories
- Story-point estimation
- Sprint board
- Burndown chart
- Reflection questions and answers

## Outcome
The project work is structured into manageable tasks and planned sprints, supporting progress tracking and Agile project management.
